# ติดตั้งระบบแจ้งซ่อมที่ www.ben2.ac.th/repair

เอกสารสำหรับ**ผู้ดูแลเว็บโรงเรียน** (ผู้ที่เข้า File Manager / FTP / แอดมิน WordPress ของ ben2.ac.th ได้)
ครูที่ปรึกษาอนุญาตให้ใช้ที่อยู่ `https://www.ben2.ac.th/repair` แล้ว ตอนนี้ที่อยู่นี้ยังว่าง (ขึ้น 404)

## ระบบนี้คืออะไร / กระทบเว็บโรงเรียนไหม

- เป็น **ไฟล์เว็บธรรมดา** (HTML / CSS / JavaScript รวม 13 ไฟล์ ขนาดประมาณ 24 KB) **ไม่ใช้ PHP ไม่ใช้ฐานข้อมูล ไม่ต้องติดตั้งปลั๊กอิน**
- ข้อมูลใบแจ้งซ่อมเก็บใน Google Sheets ของโรงเรียนผ่าน Google Apps Script (อยู่นอกเซิร์ฟเวอร์โรงเรียน) เซิร์ฟเวอร์โรงเรียนแค่ส่งไฟล์เว็บให้
- **ไม่ต้องแก้ WordPress, ไม่ต้องแก้ธีม, ไม่ต้องแก้ไฟล์เดิมใด ๆ** ทุกวิธีด้านล่างเพิ่มของใหม่เท่านั้น
- ไฟล์ไม่มีรหัสผ่านหรือความลับ รหัสผ่านช่างอยู่ใน Google Apps Script

## เลือกวิธีที่ทำได้ (เรียงตามที่แนะนำ)

### วิธี A — วางไฟล์ในโฟลเดอร์ `repair` (แนะนำ)

ได้ที่อยู่จริง `www.ben2.ac.th/repair` ไม่ต้องใช้ iframe ใช้งานบนมือถือได้เต็มที่

1. เข้า File Manager (cPanel) หรือ FTP ไปที่โฟลเดอร์รากของเว็บ — โฟลเดอร์ที่มี `wp-content`, `wp-config.php`
2. สร้างโฟลเดอร์ใหม่ชื่อ **`repair`** (ตัวพิมพ์เล็กทั้งหมด)
3. อัปโหลดไฟล์ **`ben2-repair-site.zip`** ไปไว้ในโฟลเดอร์ `repair` แล้วสั่ง Extract (หรืออัปโหลดไฟล์ในโฟลเดอร์ `dist/repair` ที่แนบมาก็ได้)
4. ตรวจว่าไฟล์อยู่ตำแหน่งนี้ **`repair/index.html`** (ไม่ใช่ `repair/repair/index.html`) และมีโฟลเดอร์ `repair/js/`
5. ลบไฟล์ zip ออกจากเซิร์ฟเวอร์หลังแตกไฟล์เสร็จ

ปลอดภัยต่อ WordPress: Apache ส่งไฟล์ในโฟลเดอร์ที่มีอยู่จริงก่อน จึงไม่ถูก WordPress ดักไป

**(ไม่บังคับ) `.htaccess` ให้เบราว์เซอร์โหลดไฟล์ใหม่ทันทีเมื่อมีการอัปเดต** — สร้างไฟล์ `repair/.htaccess`:

```apache
<IfModule mod_headers.c>
  <FilesMatch "\.(html|js|css)$">
    Header set Cache-Control "no-cache"
  </FilesMatch>
</IfModule>
```

ถ้าเปิด `/repair/` แล้วขึ้น **500 Internal Server Error** ให้ลบไฟล์ `.htaccess` นี้ออก (เซิร์ฟเวอร์ไม่อนุญาตให้ตั้งค่าแบบนี้) ระบบยังใช้งานได้ปกติ แค่หลังอัปเดตเวอร์ชันอาจต้องรอไม่กี่นาทีหรือกดรีเฟรชแรง ๆ

### วิธี B — สร้างหน้า WordPress ชื่อ `repair` แล้วฝัง iframe

ใช้เมื่อมีสิทธิ์แอดมิน WordPress แต่ไม่มีสิทธิ์วางไฟล์บนเซิร์ฟเวอร์

1. WordPress > หน้า > เพิ่มหน้าใหม่ ตั้ง **ลิงก์ถาวร (slug) เป็น `repair`**
2. ใส่วิดเจ็ต **HTML** (Elementor) หรือบล็อก **Custom HTML** แล้ววาง:

```html
<iframe src="https://repairben2.ienas.site/" title="ระบบแจ้งซ่อม"
        style="width:100%;height:90vh;min-height:640px;border:0"></iframe>
```

3. ตั้งหน้านี้เป็นแบบเต็มความกว้าง (ไม่มีแถบข้าง) และเผยแพร่

ข้อจำกัด: ฟีเจอร์ "งานของฉัน" จำรหัสงานในเบราว์เซอร์ อาจจำไม่ได้บนบางเบราว์เซอร์ (เช่น Safari) เมื่อเว็บอยู่ใน iframe และต้องให้เว็บ `repairben2.ienas.site` ยังเปิดอยู่

### วิธี C — เปลี่ยนเส้นทาง (redirect) `/repair` ไปที่เว็บแจ้งซ่อม

ง่ายที่สุด ใช้ปลั๊กอิน **Redirection** (หรือเพิ่มใน `.htaccess` ของโฟลเดอร์รากเว็บ):

```apache
Redirect 302 /repair https://repairben2.ienas.site/
```

ผู้ใช้พิมพ์ `www.ben2.ac.th/repair` แล้วจะถูกพาไปเว็บแจ้งซ่อมโดยอัตโนมัติ (แถบที่อยู่จะเปลี่ยนเป็น `repairben2.ienas.site`)

## ตรวจสอบหลังติดตั้ง (วิธี A)

- [ ] เปิด `https://www.ben2.ac.th/repair` (ไม่มี `/` ท้าย) ต้องเด้งไป `/repair/` และเห็นหน้าแจ้งซ่อม ไม่มีแถบ "โหมดสาธิต"
- [ ] เปิดบนมือถือแล้วลองแจ้งซ่อมทดสอบ 1 รายการ แนบรูปด้วย
- [ ] เปิด `https://www.ben2.ac.th/repair/admin.html` ช่างล็อกอินแล้วเห็นรายการทดสอบ
- [ ] ลบแถวทดสอบออกจาก Google Sheet
- [ ] เว็บโรงเรียนหน้าอื่น ๆ ยังเปิดได้ตามปกติ

## อัปเดตในอนาคต

- วิธี A: ผู้พัฒนาจะส่ง `ben2-repair-site.zip` ชุดใหม่ ให้อัปโหลดแตกทับในโฟลเดอร์ `repair` (ไฟล์เดิมถูกแทนที่ ไม่ต้องลบก่อน)
- วิธี B และ C: ไม่ต้องทำอะไร ผู้พัฒนาปรับปรุงที่ `repairben2.ienas.site` ให้

## หากมีปัญหา

ติดต่อผู้พัฒนา นายวีระภัทร อ่วมเกษม (KMITL) โดยแจ้งที่อยู่ที่เปิดไม่ได้และข้อความ error ที่เห็น

สำหรับผู้พัฒนา: สร้างชุดไฟล์ด้วย `powershell -ExecutionPolicy Bypass -File scripts/make-school-bundle.ps1` ได้ผลที่ `dist/repair/` และ `dist/ben2-repair-site.zip`
หลังย้ายแล้ว ให้ตั้ง Script property `SITE_URL` ใน Apps Script เป็น `https://www.ben2.ac.th/repair` เพื่อให้ลิงก์ในข้อความ LINE ชี้ถูกที่
